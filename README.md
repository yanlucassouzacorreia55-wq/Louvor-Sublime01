# Site Louvor Sublime

Site oficial do departamento de jovens da Assembleia de Deus Jardim das Orquídeas.

## Tecnologias

- React e TypeScript
- TanStack Start e TanStack Router
- Tailwind CSS
- Supabase

## Desenvolvimento local

Requisitos: Node.js e Bun.

```sh
bun install
bun run dev
```

Para gerar a versão de produção:

```sh
bun run build
```

Configure as variáveis de ambiente do Supabase antes de executar a aplicação. Consulte `.env.example` para os nomes esperados.
